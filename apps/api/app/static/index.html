What this means for you: build one SafeSKU Bundle once, then upload that single ZIP here. On AWS, the browser sends the ZIP directly to S3 and SafeSKU starts the ingestion workflow automatically.
What should my bundle contain?
Recommended: CPSC recalls + SaferProducts.gov incidents + Amazon product metadata. Optional: Amazon reviews and SafeSKU linkage candidates. The ZIP must contain a manifest.json and each dataset must be declared with its source type, path, byte count and SHA-256. See docs/BUNDLE_FORMAT.md in the repository.
