# SafeSKU Amazon 200-Row Adjudication

This is a senior working adjudication of the 200-row CPSC -> Amazon product identity review sample.

Labels:
- MATCH: same underlying product entity/SKU.
- NON_MATCH: different product/entity.
- UNCERTAIN: evidence does not establish the exact variant/SKU.

This is a development annotation layer, not independent human gold-standard annotation.
Identity decisions use the source fields in the review CSV. Temporal safety classification is not part of this label.
