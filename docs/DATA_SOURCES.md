# Data Sources and Reproducibility

## CPSC recalls

SafeSKU ingests official CPSC recall records and preserves recall number, recall
metadata, product information, hazard text, dates, identifiers, and source record
IDs.

## SaferProducts.gov

SafeSKU ingests public consumer incident records and preserves incident date,
publication date, product identity fields, narratives, and source identifiers.

## Amazon Reviews 2023

SafeSKU uses the McAuley Lab Amazon Reviews 2023 product metadata as marketplace
identity context. The demo bundle contains only the compact product slice needed for
the investigation demo; the full research corpus is not committed to Git.

## SafeSKU linkage artifacts

The linkage layer contains identity candidates generated by blocking and feature
extraction. Non-UPC candidates are treated as unlabeled until reviewed or modeled;
they are not silently converted into negative training labels.

## Reproducibility principle

The Git repository should contain code and compact artifacts needed to reproduce the
judge path, while large raw datasets remain outside Git. Every exported Safety Case
contains stable evidence IDs so a reviewer can trace displayed findings back to
source records.
